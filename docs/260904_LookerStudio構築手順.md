# Looker Studio ダッシュボード構築手順

要件定義書10-2節「可視化層：Looker Studio（改善サイクルの起点）」の実装手順。
現行Studioの分析画面（Visitor数推移・ページ別ランキング・期間比較）と同等以上の
一覧性を持つダッシュボードを、GA4データソースで構築する。

- 対象GA4プロパティ: 既存プロパティ（測定ID: G-LHMWJ49W9P）
- 既存プロパティには現行サイトの計測履歴があるため、DNS切替前でも構築・検証できる
- 作成後はURL共有で閲覧権限のみを配布できる（GA4アカウント権限は不要）

## 運用中の環境（2026-09-08 構築済み）

- ダッシュボードURL: https://lookerstudio.google.com/reporting/2f200a77-9c43-4285-9aaf-e09e35def2b9
  （閲覧にはGoogleアカウントでのアクセス権が必要。共有は本レポートの「共有」から）

## 1. レポートの新規作成とGA4接続

1. [lookerstudio.google.com](https://lookerstudio.google.com) にログイン（GA4と同じGoogleアカウント）
2. 「作成」→「レポート」
3. データ接続画面で「**Google アナリティクス**」コネクタを選択
4. アカウント → プロパティ（LAplustのGA4プロパティ）を選び「追加」→「レポートに追加」
5. レポート名を「LAplust HP ダッシュボード」等に変更（左上のタイトルをクリック）

## 2. 配置するグラフ（10-2節の要件に対応）

すべて上部メニュー「グラフを追加」から。配置後、右パネルで指標・ディメンションを設定する。

### 2-1. スコアカード行（ページ上部・期間比較インサイト）

「スコアカード」を4つ横に並べ、それぞれ指標を設定:
- アクティブ ユーザー数
- 新規ユーザー数
- 表示回数（ページビュー）
- 平均エンゲージメント時間

4つとも右パネル「設定」→ 比較期間を「**前の期間**」にする → 前期間比の増減率（▲▼%）が自動表示される。

### 2-2. Visitor数の推移グラフ（現行Studio分析画面と同等）

- グラフ: 「時系列グラフ」
- ディメンション: 日付
- 指標: アクティブ ユーザー数（必要なら「表示回数」も追加して2系列に）
- スタイル: 比較期間を「前の期間」にすると前期間の点線が重なる

### 2-3. ページ別Visitor数ランキング

- グラフ: 「表」
- ディメンション: ページパスとスクリーン クラス（`pagePath`）
- 指標: アクティブ ユーザー数、表示回数、平均エンゲージメント時間
- 並べ替え: アクティブ ユーザー数の降順
- 右パネル「設定」→ 比較期間「前の期間」→ 各行に増減率が付く（伸びているコンテンツの把握）

### 2-4. 補助グラフ（任意・推奨）

- 「円グラフ」: ディメンション=デバイス カテゴリ、指標=アクティブ ユーザー数
- 「表」: ディメンション=セッションの参照元/メディア、指標=アクティブ ユーザー数（流入元の把握）

### 2-5. 期間コントロール

「コントロールを追加」→「期間設定」をページ右上に配置。
既定の期間を「過去28日間」等にしておくと、閲覧者が自由に期間を切り替えられる。

## 3. 共有設定

1. 右上「共有」
2. 「リンク設定」→「**リンクを知っている全員が閲覧できる**」または特定メンバーのメールを追加（閲覧者）
   - 社外に見せない場合はドメイン限定（laplust.com のユーザーのみ）が安全
3. 発行されたURLを社内に共有（閲覧にGA4の権限は不要）

## 4. 運用（要件定義書10-3節の改善サイクル）

- 週次または月次でダッシュボードを確認し、数値の要約（またはスクリーンショット）を
  Claude Codeに共有 → 変化点の分析と改善案の提示 → 実装 → 再計測、のループを回す
- DNS切替後は新サイトの計測が同じプロパティに連続して記録されるため、
  ダッシュボードはそのまま移行前後の比較にも使える
- 補足: フォーム送信はGA4拡張計測の「フォームの操作」イベント（form_submit）で
  自動計測される。CVRを追う場合は、GA4管理画面でform_submitを
  キーイベント（コンバージョン）に指定し、ダッシュボードに指標として追加する

## 5. 問い合わせ件数の可視化（任意・2ページ目）

問い合わせ管理スプレッドシートをデータソースに追加すると、問い合わせ件数の推移も
同じレポートで見られる:

1. 上部メニュー「ページを追加」→ 新ページ
2. 「データを追加」→「**Google スプレッドシート**」→ HP問い合わせ管理 → タブ「お問い合わせ」
3. 「時系列グラフ」: ディメンション=受信日時（日付に型変換）、指標=Record Count
4. 同様にタブ「LA-Eye資料請求」「LA-OCA無料申し込み」も追加可能
