# ニュースリリース公開手順（Claude側の作業ルール）

担当者がNotionで書いた記事を、サイトのニュースリリースとして公開する際のClaude側の手順。
担当者向けの手順はNotion「コーポレートサイト」ページの
「⭐ ニュースリリース記事の作成手順」を参照（テンプレート複製→記入→リンクをClaudeへ）。

## 入力

- Notionページのリンク（テンプレート「📰 ニュースリリース記事テンプレート」の複製に
  タイトル・基本情報・アイキャッチ・本文が記入されたもの）

## 変換ルール（Notion → Markdown）

1. Notion MCP（notion-fetch）でページを取得する
2. frontmatterへのマッピング（仕様: docs/260901_frontmatter仕様.md）
   - `title`: ページタイトル
   - `date`: 基本情報テーブルの「公開日」
   - `categories`: 「カテゴリ」（company / technology / event / other、複数可）
   - `category`: categoriesの先頭（記事ページのパンくず・チップ表示用）
   - `description`: 「概要」
   - `cover` / `ogImage`: アイキャッチ画像（下記の画像処理後のローカルパス）
   - `sortIndex`: 新規記事には不要（日付降順で先頭に並ぶ）
3. `slug`: 記事内容を表す短い英数字小文字（例: `laeye_release_0-0-14`）。
   既存記事と重複しないこと。URLは `/news_contents/<slug>` になる
4. ファイル名: `site/content/news/yymmdd_<slug>.md`（yymmdd=公開日）
5. 本文: 見出しは `##`（h2）/`###`（h3）、段落・リスト・太字・リンクをそのまま変換。
   Notion固有ブロック（コールアウト等）は近い表現（引用等）に落とす
6. 画像処理（重要）:
   - Notionの画像URLは**期限付き署名URLのため直接参照してはいけない**
   - アイキャッチ・本文画像をすべてダウンロードし、
     `site/public/assets/news/yymmdd_<slug>/` に保存して `/assets/news/...` で参照する
   - ファイル名は `eyecatch.<ext>`、本文画像は `01.<ext>`, `02.<ext>` … の連番

## 公開フロー

1. `dev` からブランチを切る（例: `news/yymmdd-<slug>`）
2. Markdownと画像を追加してビルド（sitemapにも自動反映される）
3. ローカルQA: 記事ページ・ニュース一覧（サムネイル）・該当カテゴリページの表示確認
4. devへマージ→push
5. **mainへ反映してデプロイ**（記事の「公開してください」という依頼は
   main反映の明示指示とみなしてよい。ただしdevにリリース未確認の他の変更が
   溜まっている場合は、mainへは記事のコミットのみをcherry-pickするか、
   ユーザーにdevごと反映してよいか確認する）
6. デプロイ後、本番URLで表示確認して担当者に完了報告（記事URLを添える）

## 更新・取り下げ

- **更新**: 同じNotionページの再取得→該当Markdown・画像を上書き→同フローで反映
- **取り下げ**: 該当Markdownを削除（画像フォルダも削除）→同フローで反映。
  公開済みURLへのアクセスは404になるため、必要に応じてリダイレクトを検討
