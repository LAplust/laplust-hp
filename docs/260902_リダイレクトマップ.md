**実装（2026-09-19以降）**：このマップは以下の2ファイルとして実装済み。
リダイレクトを追加・変更する場合は必ず両方を同期させること。

- `site/public/_redirects` … Netlify / Cloudflare Pages形式（ホスティングを戻す場合に有効）
